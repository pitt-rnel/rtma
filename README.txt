This directory contains RTMA - the Real-Time Messaging Architecture.
The sub-directories are organized as follows:

bin    - executables modules
build  - cmake generated build files
cmake - cmake package config
doc     - documentation
examples - example programs showing how to use RTMA
include - include files for the C++ API
lang    - API-s for other languages
lib     - library files for the C++ API
src     - source code for C++ API and executable modules
tests   - build tests
